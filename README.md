# Potato Bloodline

A browser-based survival rogue-like game built with Phaser 3. Survive waves of enemies as a potato, collect XP, and upgrade your weapons.

## Controls

- **WASD / Arrow Keys** - Move
- **Mouse Click** - Move toward cursor

## Commands

```bash
npm install
npm run dev
npm run build    # Production build
npm run preview  # Preview build
```

Open http://localhost:3000

## Tech Stack

- Phaser 3
- Vite
- Vanilla JavaScript
